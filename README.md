# Bot 余额感知

让机器人**知道自己"没钱了"**：实时检查对话、语音、视觉三类服务的余额与可用性，异常时用她自己的口吻私聊你——不是冷冰冰的"余额不足"，而是"肚子有点饿了"、"嗓子哑了说不出话"、"眼前一片模糊看不太清"。

## 三类能力怎么判断

| 能力 | 数据来源 | 说明 |
|---|---|---|
| **对话**（DeepSeek） | `GET /user/balance` | 官方余额接口，直接读 `total_balance` |
| **视觉**（智谱 GLM） | 账户报告接口 + **免费模型探活** | 关键：GLM-Flash 系列免费，**余额为 0 也能正常用**。所以先查余额，再发一个最小请求探活；探活成功就不报警额 |
| **语音**（火山豆包） | 最近的合成记录 | 火山没有余额查询接口（需要 AK/SK 签名），改为读 `seed_audio_calls.jsonl`，连续失败即判定不可用 |

## 分级与说法

| 能力 | 余额低 / 偶发失败 | 见底 / 多数失败 | 不可用 / 连续失败 |
|---|---|---|---|
| 对话 | 「肚子有点饿了，脑子转得比平时慢半拍…（还剩 ¥3.20）」 | 「饿得厉害，快没力气思考了…」 | 「脑袋空空的，什么都想不起来…（对话服务连不上了）」 |
| 语音 | 「嗓子有点干，说话有点费劲…」 | 「嗓子哑了，暂时说不出话…」 | 「嗓子完全哑了，一句话都说不出来…」 |
| 视觉 | 「眼睛有点花，看东西得凑很近…」 | 「眼前一片模糊，看不太清楚了…」 | 「眼睛睁不开了，什么都看不见…」 |

恢复正常时也会说一句：「休息了一会儿，脑子清爽多了」「嗓子润开了」「眼睛缓过来了」。

## 不打扰的设计

- 只在**状态变化**时提醒，不是每次都喊
- 同类问题有冷却（默认 6 小时），冷却期内不重复
- 轻微回转（如「不可用」→「见底」）不报，等真正恢复才说
- 提醒发到你的私聊（`owner_session`，留空取 AstrBot 管理员）
- 状态持久化在插件数据目录，重启不会重复提醒

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| enabled | true | 总开关 |
| owner_session | 空 | 提醒发给谁；留空取管理员私聊 |
| check_interval_minutes | 30 | 检查间隔 |
| llm_provider_source | deepseek_default_source | 对话凭证 id（`provider_sources` 里的） |
| llm_low_balance | 5.0 | 对话余额预警线（元） |
| vision_provider_source | snowbot-caption_source | 视觉凭证 id |
| voice_enabled | true | 是否检查语音 |
| voice_log_path | 空 | 语音调用日志；留空读 data/temp/seed_audio_calls.jsonl |
| notify_cooldown_hours | 6 | 同类提醒冷却 |
| include_detail | true | 提醒里带具体金额 |

## 依赖

纯标准库 + aiohttp（AstrBot 自带）。不需要额外 Key——直接复用 AstrBot 里已配置的 provider 凭证。

## 注意

- 智谱的余额接口来自控制台内部接口（非官方文档公开），可能随平台调整失效；失效时视觉检查会保守地跳过，不会误报。
- 火山语音没有余额接口，只有"用不了"才能感知，无法提前预警余额。
